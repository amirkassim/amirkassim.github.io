## ✨ Key Highlights

- **100% Pure HTML, CSS & JavaScript**: No external frontend framework dependencies required.
- **Offline First**: Automatically caches assets using a Service Worker (`sw.js`) so the portfolio works with or without internet.
- **Dark / Light Mode**: Instant toggle with local storage persistence and system preference detection.
- **Interactive Project Filtering**: Instant category switching (Networking, Surveillance, Systems & ERP, Web).
- **Responsive Layout**: Designed for mobile phones, tablets, and wide monitors.
- **Printable Resume View**: Dedicated printable CV template accessible from the header and hero.
- **Contact Utilities**: One-click vCard download (`.vcf`), quick email and phone clipboard copy, and interactive inquiry form.
