Ethio Installers Listing Web App & Technician Marketplace

A responsive, full-stack directory listing web application and quotation platform designed to connect commercial and residential clients across Ethiopia with verified CCTV, network cabling, access control, and telecom technicians.

Project Overview

Finding certified, trusted field technicians for CCTV installations, structured optical fiber splicing, and network server setups in Ethiopia has traditionally relied on informal word-of-mouth recommendations, leading to inconsistent workmanship, price gouging, and zero accountability.

To solve this industry challenge, I engineered Ethio Installers, a modern web-based directory and marketplace connecting building owners, hotels, corporate IT managers, and homeowners directly with verified security and telecom installers.

The platform features technician profile showcases with verified certification badges (Hikvision HCSA, Cisco CCNA), photographic portfolio case studies, instant quotation request forms, location-based sub-city filters, and a direct WhatsApp integration enabling frictionless lead conversion.

Business Goals & Objectives

Verified Installer Trust
Implement strict admin credential verification (HCSA, CCNA, Trade Licenses) to ensure client confidence.
Rapid Quote Turnaround
Enable clients to submit project requirements (camera count, building size, cable drops) and receive quotes in hours.
Regional Geo-Filtering
Dynamic filtering across Addis Ababa sub-cities (Bole, Kirkos, Yeka, Nifas Silk) and regional industrial hubs.
Mobile-First Performance
Deliver lightweight, sub-second page loads optimized for local 3G/4G mobile devices with offline caching.

Technical Challenges & Solutions

Image Optimization & Bandwidth
Implemented client-side WebP compression for high-res portfolio project uploads, reducing bandwidth load by 68%.
Direct WhatsApp Lead Routing
Generated pre-formatted URL parameters passing project category, location, and estimate direct into technician WhatsApp chats.
