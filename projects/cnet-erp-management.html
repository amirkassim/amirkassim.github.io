Project Overview

Sunland International Hotel relies on CNET Hospitality ERP as its operational core for guest reservation lifecycles, check-ins/check-outs, multi-currency invoicing, banquet billing, room service orders, inventory costing, and ERCA fiscal tax printer integration.

As Systems Administrator and Lead IT Engineer, I configured and maintained the primary Windows Server 2022 and Microsoft SQL Server environment hosting CNET ERP. I established automated maintenance plans, database index re-indexing, transaction log truncation, and real-time POS transaction replication across all food & beverage outlets.

To guarantee zero data loss, I built an automated 3-2-1 backup pipeline comprising local RAID-10 SQL snapshots, on-premise NAS cold archives, and encrypted off-site cloud mirrors.
