Project Overview

Sunland International Hotel is a modern, luxury hospitality establishment comprising multiple guest floors, conference halls, dining restaurants, wellness centers, and executive offices in Addis Ababa. The management required a world-class, fault-tolerant technological backbone to empower all front-desk operations, guest connectivity, administrative systems, and physical security without single points of failure.

As Lead Network Administrator & Systems Engineer, I planned, designed, budgeted, procured, and implemented the hotel's entire IT infrastructure from the ground up. This multi-discipline project encompassed building the Main Distribution Frame (MDF) server room, installing structured Cat6A horizontal cabling and OM3 multi-mode fiber vertical risers, configuring Cisco Catalyst core/distribution switching layers, deploying enterprise high-density Wi-Fi 6 access points, establishing an IP PBX telephony system with SIP trunking, and deploying an 80+ camera Hikvision IP CCTV surveillance network.

Following commissioning, I instituted automated network monitoring, daily cloud and local SQL snapshots, and standard operating procedures (SOPs), and continue to provide managed technical support with guaranteed 99.9% operational uptime.

Business Goals & Project Objectives

Zero-Downtime Infrastructure
Implement redundant power (dual online UPS + automatic generator failover) and redundant link aggregation (LACP) across switch stacks.
Flawless Guest Connectivity
High-density 802.11ax Wi-Fi with fast 802.11r/k roaming across 100+ guest rooms, lobbies, and 500-seat banquet halls.
Integrated IP Telephony
Deliver crystal-clear voice calling to all guest rooms and admin extensions with automated IVR, room status billing, and wake-up calls.
Strict Network Security
Hardened 802.1Q VLAN segmentation separating Guest Wi-Fi, CNET PMS Server, CCTV cameras, VoIP SIP traffic, and IPTV multicast.

Key Challenges & Engineering Solutions

Reinforced Concrete RF Attenuation
Conducted extensive Ekahau predictive and active RF surveys to calculate precise AP placements, mitigating concrete pillar RF shadowing.
CCTV & IPTV Bandwidth Contention
Applied strict DiffServ QoS policies and IGMP snooping to guarantee voice and live multicast streams receive top scheduling priority.

My Role & Responsibilities

I served as the Lead Project Engineer and Network Administrator, directing a team of 4 cabling technicians and coordinating directly with hotel general managers, electricians, and software vendors.

  • Engineered the complete MDF/IDF network topology, rack layout diagrams, and cable management pathways.
  • Configured Cisco Catalyst core switches, access switches, 802.1Q VLANs, DHCP relay pools, and inter-VLAN ACL firewall rules.
  • Deployed Grandstream UCM IP PBX with 120+ SIP phone endpoints, customized multi-lingual IVR, and room extension mapping.
  • Installed and focused 80+ Hikvision 4MP/4K IP cameras, configured 32-channel RAID-5 NVRs, and set up the 24/7 security control room.
  • Administer CNET Hospitality ERP on Windows Server 2022, establishing automated SQL snapshot rotations and off-site archives.
